# Student Management System - Java Internship Task

A console-based **Student Management System** written in Java. This project allows adding, searching, updating, and displaying student records using static array storage.

## Features

- **Add Student**: Add a new student record with a unique ID, Name, and Age.
- **Search Student**: Search for an existing student by their Student ID.
- **Update Student**: Update details (Name and Age) of an existing student using their ID.
- **Display Students**: View all stored student records formatted in a table view.

## Requirements

- **Java Development Kit (JDK)**: Java 8 or higher.

## How to Run

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sivasekhar-939/java-internship04.git
   cd java-internship04
   ```

2. **Compile the Java file**:
   ```bash
   javac StudentManagementSystem.java
   ```

3. **Run the application**:
   ```bash
   java StudentManagementSystem
   ```
